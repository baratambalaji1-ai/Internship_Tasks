# Finding the Percentage

The provided code stub reads a dictionary containing key/value pairs of `name: [marks]` for a list of students.

Print the average of the marks for the student whose name is provided, showing exactly two decimal places.

## Example

The `query_name` is `'beta'`. Find the average score of the student named `beta`.

## Input Format

- The first line contains the integer `n`, the number of students' records.
- The next `n` lines contain the names and marks obtained by a student, each value separated by a space.
- The final line contains `query_name`, the name of the student to query.

## Constraints

## Output Format

Print one line containing the average of the marks obtained by the specified student, correct to two decimal places.
