# HackerRank - Arithmetic Operators

## Problem Statement

The program reads two integers, `a` and `b`. Print three lines:

1. The sum of the two numbers (`a + b`).
2. The difference between the two numbers (`a - b`).
3. The product of the two numbers (`a * b`).

## Input Format

- The first line contains integer `a`.
- The second line contains integer `b`.

## Sample Input

```text
3
2
```

## Sample Output

```text
5
1
6
```

## Python Solution

```python
if __name__ == '__main__':
    a = int(input())
    b = int(input())

    print(a + b)
    print(a - b)
    print(a * b)
```
