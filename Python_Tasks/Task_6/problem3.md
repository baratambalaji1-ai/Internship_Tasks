# Python: Division – HackerRank

**Problem:** Given two integers `a` and `b`, print the results of integer division and float division on separate lines.

**Input Format:**
- The first line contains integer `a`.
- The second line contains integer `b`.

**Output Format:**
- Print the integer division result (`a // b`) on the first line.
- Print the float division result (`a / b`) on the second line.

**Sample Input**
```text
4
3
```

**Sample Output**
```text
1
1.33333333333
```
