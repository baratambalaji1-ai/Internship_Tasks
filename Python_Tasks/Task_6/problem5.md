# Print Function

## Problem Statement

The included code stub will read an integer, `n`, from STDIN.

Without using any string methods, print the numbers from `1` to `n` consecutively, without spaces between them.

### Example

If `n = 3`, print the numbers `1`, `2`, and `3` together.

### Input Format

The first line contains an integer, `n`.

### Constraints

- \(1 \leq n \leq 150\)

### Output Format

Print the integers from `1` through `n` as a single string, without spaces.

### Sample Input 0

```text
3
```

### Sample Output 0

```text
123
```
