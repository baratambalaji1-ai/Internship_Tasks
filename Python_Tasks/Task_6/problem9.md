# What's Your Name?

## Problem

You are given the first name and last name of a person on two different lines. Your task is to read them and print the following:

`Hello firstname lastname! You just delved into python.`

## Function Description

Complete the `print_full_name` function in the editor below.

`print_full_name` has the following parameters:

- `string first`: the first name
- `string last`: the last name

## Output Format

Print the following string:

`Hello first last! You just delved into python.`

Replace `first` and `last` with the person's first name and last name.

## Input Format

The first line contains the first name, and the second line contains the last name.

## Constraints

The length of the first and last names are each less than or equal to 10 characters.

## Sample Input 0

```text
Ross
Taylor
```

## Sample Output 0

```text
Hello Ross Taylor! You just delved into python.
```

## Explanation 0

The input read by the program is stored as a string data type. A string is a collection of characters.
