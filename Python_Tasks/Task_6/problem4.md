# Loops

## Problem Statement

The provided code stub reads an integer, `n`, from STDIN. For all non-negative integers `i` less than `n`, print `i²` (the square of `i`).

### Example

If `n = 5`, the non-negative integers less than `n` are `0, 1, 2, 3, 4`.

Print the square of each number on a separate line.

### Input Format

The first and only line contains the integer `n`.

### Constraints

- \(1 \leq n \leq 20\)

### Output Format

Print `n` lines, one corresponding to each integer `i`, where `0 ≤ i < n`. Each line contains the square of `i`.

### Sample Input 0

```text
5
```

### Sample Output 0

```text
0
1
4
9
16
```
